# Boys & Girls Club of the Permian Basin - Marketing Pitch Deck

A professional, slide-deck style web presentation matching Anecdotal's brand identity.

## Features

- **Slide-deck format** with smooth transitions
- **Multiple navigation methods:**
  - Arrow keys (left/right, up/down)
  - Spacebar (forward)
  - Mouse wheel/trackpad scroll
  - Touch/swipe on mobile
  - Click navigation dots at bottom
- **Responsive design** works on desktop, tablet, and mobile
- **Matches Anecdotal branding:**
  - Cream background (#fffce8)
  - Terracotta accent (#cc5033)
  - Sage green and teal highlights
  - Libre Caslon Text and Inter fonts
  - Glassmorphism effects with backdrop blur
  - 28px rounded corners

## Slides

1. **Title** - Partnership introduction
2. **Your Impact** - Stats about BGC Permian Basin
3. **What We Heard** - Current challenges
4. **Our Approach** - Marketing funnel visualization
5. **Package 1** - Story & Awareness Foundation ($4,500)
6. **Package 2** - Impact Infrastructure ($7,500 + $2k/mo)
7. **Package 3** - Flagship Impact Partnership ($24,500 + $2k/mo)
8. **Investment Summary** - Pricing comparison
9. **Next Steps** - Call to action

## How to Use

1. Open `index.html` in any modern web browser
2. Navigate using arrow keys, mouse wheel, or touch gestures
3. Present full-screen for best effect (F11 or browser full-screen mode)
4. Share the link or host on your website

## Sharing Options

- **Local presentation:** Open directly from your computer
- **Host online:** Upload to your web hosting, Netlify, Vercel, or GitHub Pages
- **Share as PDF:** Use browser print > Save as PDF (though interactive features will be lost)

## Customization

All content, colors, and styling can be modified in the single `index.html` file. The CSS is embedded in the `<style>` section.
